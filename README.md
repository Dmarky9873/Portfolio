# Daniel Markusson — Portfolio

An editorial, recruiter-first portfolio built with Astro and TypeScript.

## Local development

Use Node.js 22.12 or newer (`nvm use` will select the pinned version), then run:

```sh
npm install
npm run dev
```

## Quality checks

```sh
npm run check
npm run build
```

The contact form uses EmailJS. Copy `.env.example` to `.env` to override the configured service, template, or public key.
